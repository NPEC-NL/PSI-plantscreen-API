plantscreen.TrayApi

All URIs are relative to https://localhost:44339

Method HTTP request Description
scales_mapping_tray GET /ScalesMapping/Tray Returns a scales mapping for tray defined by ID.
tray GET /Tray Returns one tray by tray ID.
tray_profile GET /TrayProfile Returns one tray profile by tray profile ID.
tray_profile_to_date_tray GET /TrayProfile/ToDate/Tray Returns one tray profile to which tray defined by ID was assigned on the defined time.
tray_profile_tray GET /TrayProfile/Tray Returns one tray profile to which tray defined by ID is assigned.
tray_profile_used_tray GET /TrayProfile/Used/Tray Returns tray profiles to which tray defined by ID was assigned between defined times. Times is entered as the start and end time of the required interval. All tray profiles assigned to tray between these times will be returned.
tray_round GET /Tray/Round Returns all trays measured in the round defined by ID.
tray_type GET /TrayType Returns one tray type by tray type ID.
tray_type_tray GET /TrayType/Tray Returns one tray type which is assigned to the tray defined by ID.
tray_type_tray_profile GET /TrayType/TrayProfile Returns one tray type which is assigned to the tray profile defined by ID.
