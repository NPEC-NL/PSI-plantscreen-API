swagger_client.ScalesApi

All URIs are relative to https://localhost:44339/

Method HTTP request Description
scales_plant_weight GET /Scales/PlantWeight Returns scales data for tray defined by tray ID, by round ID of round in which the tray was measured and by device defined by device ID.
scales_plant_weight_measure GET /Scales/PlantWeight/Measure Returns scales data by measure ID.
scales_weight_reference_plant GET /Scales/WeightReference/Plant Returns plant weight reference data by plant ID. The weight is in units of grams
scales_weight_reference_to_date_tray GET /Scales/WeightReference/ToDate/Tray Returns plant weight reference data by plant ID. The weight is in units of grams
scales_weight_reference_tray GET /Scales/WeightReference/Tray Returns plant weight reference data by tray ID. The weight is in units of grams
