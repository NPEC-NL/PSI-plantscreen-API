swagger_client.SystemLogApi

All URIs are relative to https://localhost:44339/

Method HTTP request Description
system_log_date_log_tag GET /SystemLog/Date/LogTag Returns important events as system logs by log tag between defined times. Times is entered as the start and end time of the required interval.
system_log_date_log_type GET /SystemLog/Date/LogType Returns important events as system logs by log type between defined times. Times is entered as the start and end time of the required interval.
system_log_date_round GET /SystemLog/Date/Round Returns important events as system logs by round ID between defined times. Times is entered as the start and end time of the required interval. System logs are only optionally assigned to the round.
system_log_date_tray GET /SystemLog/Date/Tray Returns important events as system logs by tray ID between defined times. Times is entered as the start and end time of the required interval. System logs are only optionally assigned to the tray.
system_log_log_tag GET /SystemLog/LogTag Returns a list of all used system log tag.
system_log_log_type GET /SystemLog/LogType Returns a list of all used system log types.
system_log_round GET /SystemLog/Round Returns important events as system logs by round ID. System logs are only optionally assigned to the round.
system_log_tray GET /SystemLog/Tray Returns important events as system logs by tray ID. System logs are only optionally assigned to the tray.
