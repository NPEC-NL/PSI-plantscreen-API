swagger_client.SpectrumDeviceApi

All URIs are relative to https://localhost:44339/

Method HTTP request Description
spectrum_device GET /SpectrumDevice Returns one spectrum device by spectrum device ID.
spectrum_device_id GET /SpectrumDeviceID Returns a list of all spectrum device IDs in the database.
spectrum_values_date_device GET /Spectrum/Values/Date/Device Returns spectrum values for spectrum device defined by spectrum device ID measured between times. Times is entered as the start and end time of the required interval.
