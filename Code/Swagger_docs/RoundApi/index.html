swagger_client.RoundApi

All URIs are relative to https://localhost:44339/

Method HTTP request Description
round GET /Round Returns one round by round ID.
round_date_experiment GET /Round/Date/Experiment Returns all rounds measured in the experiment defined by ID between defined times. Times is entered as the start and end time of the required interval.
round_experiment GET /Round/Experiment Returns all rounds measured in the experiment defined by ID.
round_order_date_experiment GET /RoundOrder/Date/Experiment Returns all rounds measured in the experiment defined by ID between defined times. Times is entered as the start and end time of the required interval.
round_order_experiment GET /RoundOrder/Experiment Returns all rounds measured in the experiment defined by ID.
round_order_round GET /RoundOrder/Round Returns the round order in the experiment by round ID.

JsonRoundResult round(id)
